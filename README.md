# Алиса и Искорка: три звёздочки

Браузерный платформер для Алисы. Управление с геймпада (стик, нижняя кнопка — прыжок, левая — позвать Искорку) или с клавиатуры (стрелки, пробел, X).

- `index.html` — готовая игра одним файлом, открывается в браузере.
- `game.js` — код игры.
- `assets.json` — спрайты и кадры мультфильма.
- `tools/build.py` — собирает `dist/index.html` из `game.js` и `assets.json`.
- `tools/cut.py`, `tools/pack.py` — вырезают спрайты из листов персонажей (папка `src/`) и упаковывают их.
